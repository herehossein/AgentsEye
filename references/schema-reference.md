# agentsEye Schema Reference

> **Tool**: `agentsEye` v1.0.0  
> **Schema Version**: `1.0`  
> **Output Formats**: `minimalSummary` (stdout), `report.json` (disk artifact), `diffReports` (structural diff)  

This reference document defines the complete schema specifications for all payloads generated by `agentsEye`.

---

## 1. Compact stdout Schema (`minimalSummary`)

The default output printed to stdout upon running `node agentsEye.mjs <url>`. It is compact and much smaller than a full DOM dump so autonomous agents can consume runtime feedback without saturating their context window.

### TypeScript Definition

```typescript
export interface MinimalSummary {
  /** Execution status (true if probe completed, false on fatal error) */
  ok: boolean;

  /** Schema version identifier (e.g. "1.0") */
  schemaVersion: "1.0";

  /** Top-level prompt injection audit & safety status */
  security: {
    promptInjectionDetected: boolean;
    threatLevel: "clean" | "medium" | "high" | "critical";
    notice: string;
    findingsCount: number;
    findings?: Array<object>;
  };

  /** Target URL and navigation metadata */
  target: {
    requestedUrl: string;
    finalUrl: string;
    title: string | null;
    httpStatus: number | null;
  };

  /** Local run artifacts path pointers */
  run: {
    id: string;             // e.g. "2026-10-23T17-45-12-849Z-a9f2"
    directory: string;      // Full filesystem path to run folder
    report: string;         // Full path to report.json
  };

  /** Emulated viewport resolution and DPR */
  viewport: {
    width: number;
    height: number;
    dpr: number;
    mobile: boolean;
  };

  /** Total probe execution duration in milliseconds */
  durationMs: number;

  /** Core Web Vitals observed snapshot */
  performance: {
    lcp: number | null;     // Largest Contentful Paint (ms)
    cls: number | null;     // Cumulative Layout Shift score
    fcp: number | null;     // First Contentful Paint (ms)
    fid: number | null;     // First Input Delay (ms)
    inp: number | null;     // Interaction to Next Paint (ms)
  };

  /** Critical layout diagnostics */
  layout: {
    horizontalOverflow: boolean;  // True if document scroll width > viewport width
    scrollTrap: boolean;          // True if vertical scroll is trapped by overflow: hidden
    nodes: number;                // Count of rendered DOM element nodes
    issueCounts: Record<string, number>;
  };

  /** Top detected layout & accessibility issues (capped at 8) */
  issues: Array<{
    code: IssueCode;
    severity: "error" | "warn" | "info";
    message: string;
  }>;

  /** High-level network summary */
  network: {
    total: number;
    failed: number;
    statusClasses: Record<string, number>; // e.g. { "2xx": 24, "4xx": 1 }
    byType?: Record<string, number>;
  } | null;

  /** Console log counts and sample errors */
  console: {
    counts: { log?: number; warn?: number; error?: number; info?: number; debug?: number };
    errors: Array<{ text: string; url?: string; lineNumber?: number }>;
  };

  /** Uncaught exceptions and runtime errors */
  errors: {
    uncaughtCount: number;
    logErrorCount: number;
    uncaught: Array<{ text: string; url?: string; lineNumber?: number; stack?: string }>;
    logErrors: Array<{ text: string; url?: string; lineNumber?: number }>;
  };

  /** Handled browser dialogs (alert/confirm/prompt) */
  dialogs: {
    count: number;
    items: Array<{ type: string; message: string; defaultPrompt?: string }>;
  };

  /** ARIA landmarks and main content selectors */
  landmarks: Record<string, { count: number; items?: string[] }>;

  /** Heading hierarchy and outline */
  headings?: {
    count: number;
    items: Array<{ level: number; tag: string; text: string }>;
    outline: string[];
  };
  headingsOutline?: string[];

  /** Scoped DOM subtree (present when --selector is specified) */
  dom?: {
    selector: string;
    selectorMatched: boolean;
    tree: object;
    stats: object;
  };

  /** Root CSS custom properties (present when --css-vars or detected) */
  cssVars?: {
    count: number;
    vars: Record<string, string>;
  };

  /** Non-fatal execution warnings */
  warnings: string[];

  /** Truncation flag if DOM exceeded limits */
  truncated?: boolean;

  /** Multi-breakpoint summary (only present if --matrix was specified) */
  matrix?: {
    viewports: Array<{
      viewport: { width: number; height: number };
      issues: number;
      overflow: boolean;
    }>;
    differences: Array<DiffSummary>;
  };

  /** UI interaction summary (only present if --explore or --click was specified) */
  interactions?: {
    performed: number;
    explored: number;
    diff: DiffSummary | null;
  };
}
```

## 2. Complete Telemetry Schema (`report.json`)

Saved locally to `.agentsEye/runs/<run-id>/report.json`. This document contains unbudgeted, high-fidelity browser inspection telemetry.

## 3. Diff Output Schema (`diffReports`)

Emitted when executing `node agentsEye.mjs diff <run-id-1> <run-id-2>`. Compares two runs to verify whether frontend modifications resolved layout defects without introducing regressions.

### TypeScript Definition

```typescript
export interface DiffReport {
  ok: boolean;
  schemaVersion: "1.0";
  before: string;           // Before Run ID (e.g. "2026-10-23T17-00-00-111Z-a1b2")
  after: string;            // After Run ID  (e.g. "2026-10-23T17-05-00-222Z-c3d4")
  
  /** High-level change counts */
  summary: DiffSummary;

  /** Elements added in 'after' snapshot (capped at 50) */
  added: Array<{ key: string; selector: string }>;

  /** Elements removed from 'before' snapshot (capped at 50) */
  removed: Array<{ key: string; selector: string }>;

  /** Bounding box layout shifts > 1px (capped at 50) */
  layout: Array<{
    key: string;
    selector: string;
    before: { left: number; top: number; width: number; height: number };
    after: { left: number; top: number; width: number; height: number };
  }>;

  /** Computed CSS property alterations (capped at 50) */
  styles: Array<{
    key: string;
    selector: string;
    changes: Record<string, { before: string | null; after: string | null }>;
    rendered?: { before: boolean; after: boolean };
  }>;

  /** New JavaScript errors or console errors introduced in 'after' */
  newErrors: Array<{ text: string; url?: string; lineNumber?: number; stack?: string }>;

  /** Newly introduced layout or accessibility issues */
  newIssues: Array<{ code: IssueCode; message: string; cssPath?: string }>;

  /** Flag indicating whether change arrays were truncated at 50 items */
  truncated: boolean;

  /** Operational context note */
  note: string;
}

export interface DiffSummary {
  added: number;
  removed: number;
  layoutChanged: number;
  styleChanged: number;
  newErrors: number;
  newIssues: number;
}
```

## 4. Standard Issue Codes Reference

The `issues` array in `minimalSummary` and `report.json` surfaces the following standardized codes:

| Issue Code | Severity | Trigger Threshold / Rule |
| :--- | :---: | :--- |
| `horizontal-document-overflow` | `warn` | Document scroll width exceeds viewport width: `document.documentElement.scrollWidth > innerWidth + 1` or horizontal overflow elements detected. Offending elements are recorded in `page.metrics.overflowElements` with `{ cssPath, rect }`. |
| `scroll-lock-trap-risk` | `error` | `overflow: hidden` or `position: fixed` applied to `html` or `body` while total content height exceeds inner viewport height (`contentHeight > innerHeight`). |
| `small-touch-target` | `info` | Interactive control (`button`, `a`, `input`, `select`) has physical dimensions `< 44px` width or `< 44px` height (WCAG 2.5.5 / 2.5.8 recommendation). |
| `input-font-below-16px` | `warn` | Form text input element has computed `font-size < 16px`. On iOS WebKit, tapping this input triggers an unwanted automatic page zoom. |
| `image-missing-alt` | `info` | `<img>` tag without an `alt` attribute or with missing accessibility description. |
| `duplicate-id` | `warn` | An identical `id` attribute appears on two or more distinct DOM elements in the tree. |
| `low-text-contrast` | `warn` | Text color against solid background fails WCAG 2.1 AA minimum contrast ratio (4.5:1 for regular text, 3:1 for large text). |
